# Quiz по странам и столицам.

## Установка и запуск:

1. Клонируйте репозиторий:

```bash
git clone -b
```

2. Перейдите в директорию проекта:

```bash
cd
```

3. Установите зависимости:

```bash
npm install
```

4. Запустите проект:

```bash
npm run dev
```

## Стек технологий

### Frontend

- React.js
- JavaScript (ES6+)
- CSS Modules для стилизации
- Vite как сборщик проекта
- HTML5
- CSS3
- Flexbox/Grid для построения layout

### Основные зависимости

- React Hooks (useState, useEffect)

### Структура проекта

- Компонентный подход.
- Модульная архитектура.

### Стилизация

- CSS Modules для изолированных стилей
- SVG иконки
- CSS переменные

### Инструменты разработки

- ESLint для статического анализа кода
- Prettier для форматирования кода
- Git для версионного контроля
- npm как пакетный менеджер
- Chrome DevTools для отладки
- VSCode как основной редактор

Переход на страницу с вопросом происходит при нажатии на кнопку "Начать" в начальной странице.
Возврат на начальную страницу происходит при обновлении страницы.
Переход на страницу с результатом происходит при выборе ответа на вопрос и нажатии на кнопку "Ответить".
Возврат на начальную страницу происходит при нажатии на кнопку "Попробовать еще" на странице с результатом.

Выбор вариантов ответов делается с помощью клавиш 1-4, поэтому убрал возможность выбора табом, а то как-то странно получается.
